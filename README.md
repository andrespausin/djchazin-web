# CHAZIN — djchazin.com

Official website of **Chazin** — Latin Tech House · Spain × Venezuela · Based in Bangkok.
Built from the 2026 Electronic Press Kit: black, champagne (`#C2A878`), Archivo Expanded titles and Montserrat text.

## Stack

- **Next.js 15** (App Router, every route prerendered as static HTML) + **React 19** + TypeScript
- **GSAP + ScrollTrigger** (`@gsap/react`) for entrance, scroll and page-transition animation
- **Lenis** for smooth scrolling, driven by GSAP's ticker
- `next/image` (AVIF/WebP) and `next/font/local` (self-hosted variable fonts, no external requests)

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build
npm run typecheck
```

## Routes

| Route      | Content |
|------------|---------|
| `/`        | Hero with portrait and logo reveal · latest release on a playable vinyl · club-logo marquee · live-video section (placeholder) · links to the sections · booking CTA |
| `/about`   | Biography, quote, animated counters, world-tour map with routes that draw themselves and a camera that zooms to the selected country |
| `/music`   | Releases as playable vinyl records (Spotify embed in the dock) · Spotify profile CTA · Magna Beat Records |
| `/shows`   | Club & festival logo grid that opens a venue map · flyer gallery |
| `/press`   | EPK PDF download · press photos · logos · copy-ready short bio |
| `/booking` | booking@ / info@ / Instagram |
| `/links`   | Link hub, the destination of the "All links" QR code in the EPK (no nav, mobile-first) |

The EPK PDF links to `djchazin.com/links` and `djchazin.com/press`; both exist here.

## Where things live

```
src/data/site.ts        ← ALL content: links, emails, releases, bio, clubs, flyers, countries, press files
src/data/icons.ts       ← brand icon paths (simple-icons, CC0)
src/components/
  PlayerProvider.tsx    Spotify iFrame player and dock; lives in the layout so playback survives navigation
  Visualizer.tsx        canvas bars, drawn only while a track really plays (levels from src/lib/audioLevels.ts)
  Vinyl.tsx             sleeve, sliding record, inertial spin (GSAP), play button
  TourMap.tsx           world map with camera; CountryExplorer.tsx and ShowsExplorer.tsx drive it
  Music.tsx             Marquee, SocialIcon, Arrow
  Motion.tsx            Reveal, SplitTitle, Counter, Parallax (GSAP)
  Hero.tsx, Nav.tsx, Footer.tsx, PageHeader.tsx, SmoothScroll.tsx
src/app/(site)/         pages with nav + footer; template.tsx = page transition
src/app/links/          link hub (outside the nav layout)
src/data/places.json    venue locations; run `npm run generate:map` after editing
src/assets/world-map.*  generated by `npm run generate:map` (edit cities/routes in scripts/generate-map.mjs)
public/images/          web images in WebP (`npm run convert:images` for new JPG/PNG files)
public/press/           downloadable files: high-res photos, logos, CHAZIN_EPK_2026.pdf
```

The tempo used by every beat-synced animation is `BPM` in `site.ts` and `--beat` in `globals.css` (60/124 s).

## Performance & accessibility

- All pages are static; the Spotify script loads only on the first play, and the canvas visualiser runs only while a track plays and is on screen.
- Nothing moves like audio unless audio is playing.
- `prefers-reduced-motion`: Lenis, GSAP reveals, CSS loops, record spin and the visualiser are disabled; the map jumps to the selection instead of flying.
- Long-lived cache headers for images, fonts and PDFs (`next.config.ts`).

## Deploy (Vercel)

1. Vercel → **Add New → Project** → import this repository (framework preset: Next.js, no settings needed).
2. **Settings → Domains** → add `djchazin.com` (and `www`) and create the DNS records Vercel shows at your registrar.
   If email routing lives on the same DNS, add the web records without touching the MX/TXT email records.

Every push to `master` deploys to production.
